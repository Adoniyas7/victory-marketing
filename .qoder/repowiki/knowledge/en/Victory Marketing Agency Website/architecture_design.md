- **Content-Driven Architecture**: The module separates content (JSON files in `content/`) from presentation (HTML/CSS) and logic (JS). The `ContentLoader` class (`js/content-loader.js`) acts as the central engine, fetching all JSON data in parallel and rendering it into DOM placeholders identified by `data-section` attributes in `index.html`.
- **Modular JavaScript**: Functionality is split into ES modules: `main.js` orchestrates initialization, `content-loader.js` handles data fetching and DOM injection, `animations.js` manages visual effects, `navigation.js` handles UI state, and `form.js` manages contact form interactions.
- **CSS Organization**: Styles are modularized by component or feature (e.g., `hero.css`, `team.css`, `variables.css`) and imported sequentially in the HTML head. Global design tokens are defined in `css/variables.css` using CSS custom properties.
- **Entry Point**: `index.html` serves as the single entry point, loading all CSS dependencies and the main JavaScript module (`js/main.js`) which bootstraps the application on `DOMContentLoaded`.
